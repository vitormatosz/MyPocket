MyPocket
Projeto Final do 2º Bimestre - PW2
📌 Sobre o Projeto

O MyPocket é um sistema de gestão financeira pessoal desenvolvido para aplicar os conceitos de Programação Orientada a Objetos (POO). Seu objetivo é permitir o controle de receitas, despesas e saldo de forma segura e organizada.

O sistema garante que nenhuma alteração no saldo seja feita sem validação, utilizando métodos específicos para registrar movimentações financeiras. Além disso, todas as transações são armazenadas em um histórico, permitindo o acompanhamento das finanças do usuário.

🎯 Funcionalidades
Cadastro de receitas e despesas.
Controle automático do saldo.
Histórico de transações.
Validação de dados para evitar operações inválidas.
Aplicação de conceitos como encapsulamento, herança, abstração e polimorfismo.

O projeto simula uma carteira financeira digital simples, focando na organização, segurança e manutenção dos dados financeiros.
