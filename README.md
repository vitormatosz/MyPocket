# MyPocket
Projeto Final do 2º Bimestre - PW2

O objetivo deste projeto é aplicar os conceitos de Programação Orientada a Objetos para gerenciar o saldo, receitas e despesas de um usuário de forma segura e organizada.

Diferente de scripts comuns, o MyPocket deve garantir que o saldo nunca seja alterado sem passar por uma validação e que o histórico de transações seja preservado através de instâncias de objetos.
